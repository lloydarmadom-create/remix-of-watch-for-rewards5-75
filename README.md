# Remix of Watch For Rewards5 (75)

Build the visual shell, navigation, and compliance pages for a dark-mode, mobile-first gaming and crypto rewards web app called "Watch For Rewards" using Lovable Cloud.



1. Visual Design & Human-Crafted Feel:

- Make the UI look custom, handcrafted, and authentic—avoid generic AI templates. Use a deep obsidian/slate background, rich vault cards with subtle inner borders, tactile gaming buttons, crisp typography, and vibrant emerald, cyan, and gold accents.

- Mobile-first bottom navigation bar with 5 tabs: Earn, Videos, Store, History, Profile, plus a hidden `/admin` route (create clean placeholder views for all tabs for now).

- Hide any Lovable watermark/badge via CSS.

- Include a dismissible "Accept Cookies" bottom banner, a public `/privacy` page (13+ gaming audience, email-only data, third-party advertising partner cookies, and 100% final non-appealable admin decisions—never expose any admin email publicly), and a global footer stating: "Not affiliated with Roblox Corporation."

- Do not run browser preview checks after building.
